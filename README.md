-- Python Port Tarayıcı (Port Scanner) --

Temel `socket` kütüphanesini kullanan basit bir komut satırı (CLI) port tarayıcı aracıdır.

# Özellikler
- Hedef IP adresini belirleyebilme.
- Belirlenen port aralığında (başlangıç ve bitiş portu) tarama yapabilme.
- Her port için bağlantı denemesi (TCP Connect) gerçekleştirebilme.
- Açık olan portları tespit edip ekrana raporlama.

# Nasıl Çalıştırılır?

Programı çalıştırmak için:
```bash
python3 port-tarayici.py
